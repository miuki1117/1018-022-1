# 圖片素材清單

請將具備適當使用授權的圖片下載至此資料夾，並使用以下檔名。網站已為每張圖片撰寫描述性 alt 文字。

- `hero-couple.jpg`
- `wedding-01.jpg` 至 `wedding-04.jpg`
- `record-01.jpg` 至 `record-04.jpg`
- `portrait-01.jpg` 至 `portrait-04.jpg`
- `case-wedding.jpg`
- `case-day.jpg`
- `case-portrait.jpg`
- `photographer.jpg`

## 免費圖庫建議

- Unsplash： https://unsplash.com/
- Pexels： https://www.pexels.com/

可搜尋 `wedding couple natural light`, `wedding candid`, `natural portrait` 等關鍵字。下載後請確認每張照片的授權與人物肖像規範。請勿只把圖片網址當作檔案路徑；需將圖片實際放入本資料夾，並確保檔名與 HTML 相同。
